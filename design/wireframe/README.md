# 卡小西 页面线框图

22 个页面的低保真线框图，用于评审流程，不用于视觉验收。

## 文件

| 文件 | 说明 |
|---|---|
| `contact-sheet.png` | 22 页总览（4 列 × 6 行） |
| `screens/01-boot.png` … `screens/22-success.png` | 单页原图，750×1624（2x） |
| `make_wireframe.py` | 生成脚本，改文案/布局后重新运行即可 |
| `kaxiaoxi.png` | IP 素材（从 assets/design 复制） |

## 页面清单

| # | 文件 | 页面 | 关键点 |
|---|---|---|---|
| 01 | 01-boot | 启动/登录 | 卡小西形象、微信一键登录 |
| 02 | 02-register | 注册 | 6 项必填，宿舍格式提示 |
| 03 | 03-pending | 等待审核 | 状态说明 + 联系主席 |
| 04 | 04-home | 首页 | 发布入口、近期任务、待办 |
| 05 | 05-task-list | 任务列表 | 三个 tab、状态筛选 |
| 06 | 06-task-detail | 任务详情 | **多场次**、候补人数、订阅提醒 |
| 07 | 07-publish-picker | 发布入口 | 搬砖/部门待办/年历日程 三选一 |
| 08 | 08-publish-form | 发布搬砖 | 多场次、人数不限、附件 30 天过期 |
| 09 | 09-manage | 报名管理 | 待审/通过/候补/请假，通过即占名额 |
| 10 | 10-my-signups | 我的报名 | 请假、取消、候补排位 |
| 11 | 11-calendar | 年历月视图 | 日期点、当日事件 |
| 12 | 12-event-detail | 事件详情 | 关联任务入口 |
| 13 | 13-event-edit | 新建日程 | 无重复事件 |
| 14 | 14-todo-list | 待办列表 | 个人/部门、重要性色条 |
| 15 | 15-todo-edit | 待办编辑 | 部门、负责人、优先级 |
| 16 | 16-messages | 消息中心 | 永久保留、未读标记 |
| 17 | 17-mine | 我的 | 二课/活动/待办统计 |
| 18 | 18-erke | 我的二课 | 实时统计明细 |
| 19 | 19-members | 成员管理 | 审核、按部门列表 |
| 20 | 20-erke-summary | 二课汇总 | 四列导出 |
| 21 | 21-settings | 设置 | 学年、权限移交 |
| 22 | 22-success | 报名成功 | 订阅提醒引导 |

## 重新生成

```
python make_wireframe.py
```

依赖 Pillow 与系统中文字体（Microsoft YaHei）。脚本内所有尺寸按 2x（750×1624）绘制。
