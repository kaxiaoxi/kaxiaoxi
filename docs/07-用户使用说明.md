# 卡小西 · 使用说明

> 给影协成员、部长、主席看的操作手册。遇到问题先看第 9 节「常见问题」。

---

## 1. 怎么进入

1. 微信搜索小程序「卡小西」（名称以最终上线为准），或扫协会群里的二维码；
2. 首次进入点「微信一键登录」；
3. 填写资料：**姓名、学号、学院、手机号、宿舍号、部门**（生日选填）；
4. 提交后等待主席审核，通过后会收到通知。

> 资料只用于协会内部联络，学号/电话/宿舍仅主席和本部门部长可见。

---

## 2. 首页

打开小程序先看到首页，四块内容：

| 区域 | 作用 |
|---|---|
| 发布 | 部长/主席才有：发搬砖、发部门待办、发年历日程 |
| 近期任务 | 正在报名或即将开始的活动，点进去可报名 |
| 我的待办 | 你自己的待办，按重要性排序 |
| 本周年历 | 本周协会安排 |

底部四个 Tab：**首页 / 任务 / 年历 / 我的**。

---

## 3. 报名参加活动

### 3.1 找到活动

「任务」页可以看到所有对你开放的活动，支持：

- 切换「全部 / 本部门 / 我参与的」；
- 按状态筛选：报名中、未开始、已结束、我发布的。

### 3.2 报名

点进活动详情 → 底部「报名」。

- **先到先得**：点了就成功，名额满后自动进候补；
- **报名审核**：提交后等部长/主席审核，通过才算数；
- 报名前可以填备注（比如「带 24-70」），选填。

### 3.3 名额满了怎么办

点「候补」进入排队，页面会显示你排第几位。有人请假或取消时，**候补第一位自动转正**，你会收到通知。

### 3.4 报了名去不了

在「我的报名」里点「请假」→ 填原因 → 等部长/主席审批。

- 审批通过后，名额自动让给候补同学；
- 活动开始后再请假，不会自动补人（来不及了）。

---

## 4. 收到提醒

报名成功后，页面会提示「开启提醒」。

- 点一下允许，**活动开始前 2 小时**会收到微信服务通知；
- 微信只允许提醒一次，所以多天活动只提醒第一场；
- 如果没开提醒，也可以在小程序「消息」里看到通知。

> 想更保险，可以在活动详情点「加入手机日历」。

---

## 5. 查看自己的二课

「我的」→「我的二课」：

- 顶部是本学年累计学时；
- 下面逐条列出每个活动得了多少学时；
- 数据是实时算的：活动结束自动计入，部长把你移出名单就会自动扣回。

年度汇总由主席/部长导出，不需要自己统计。

---

## 6. 年历

「年历」页按月显示协会所有安排，共 10 种类型：外拍采风、摄影讲座/培训、比赛/影展/作品评选、例会/工作会、器材体验/厂商活动、专题推文策划、联谊/年会、招新、截止日、其他。

- 点日期看当天活动，每行显示时间、名称、类型、负责人、状态；
- 点活动看详情，有关联任务的可以一键跳过去；
- 部长/主席可以点「＋ 新建」，也可以点「列表」进入表格视图。

### 6.1 列表视图（部长 / 主席）

列表视图把年历排成一张表，第一列日期固定，向右可横向滚动。列序：日期、名称、类型、地点、负责人、状态、可见。

顶部两个筛选：时间范围（本月 / 下月 / 全部）、可见范围（全部 / 公开 / 内部）。

> 列表里**不能直接改**。小程序窄屏，行内改日期和选人太容易误触，编辑一律进详情页。

### 6.2 公开与内部

- **公开**：全体成员可见；
- **内部**：只有部长与主席可见（预算、分工、筹备会这类事项），小干在任何入口都看不到。

### 6.3 状态

未开始 / 筹备中 / 已确定 / 卡住 / 已结束 / 已取消。

## 7. 待办

### 7.1 个人待办

「我的」→「我的待办」→「＋」，填标题、说明、可见范围、重要性（高/中/低）、截止日期。

可见范围选「仅自己」时，只有主责人能看到。

### 7.2 部门待办与协作

一条待办要同时回答两个问题：**谁负责**、**谁能看见并加入**。

| 可见范围 | 谁能看见 | 典型场景 |
|---|---|---|
| 仅自己 | 只有主责人 | 私事、临时记一笔 |
| 本部门 | 主责人 + 本部门全体 | 「摄影师队要拍校运会」，全队可见 |
| 全体 | 全体成员 | 需要跨部门支援的大活 |
| 内部 | 仅部长 + 主席 | 预算、分工、筹备会 |

- 主责人是唯一的；其他人看到后点「加入协作」即可，**不需要审批**；
- 加入后这条待办会出现在他的「我的」里，退出也只能退自己；
- 部长在本部门待办里新建，主席可以给任意部门建；
- 小干只能建「仅自己」的待办。

列表页有四个 tab：**我的**（我负责的 + 我参与的）、**部门**（本部门可加入、我还没加入的）、**内部**（仅部长/主席可见）、**已完成**。

### 7.3 自动待办

发布活动后，系统会自动生成两条待办，并自动对本部门可见，队里其他人也能加入：

1. 确认报名名单（报名截止前 1 天）；
2. 核对名单 + 收图（活动结束后 2 天）。

活动取消时这些待办应当作废——但任务取消功能还没上线，目前只有创建逻辑。

## 8. 部长/主席专用

### 8.1 发布活动（搬砖）

首页「＋ 搬砖」或任务页右上角「＋」，填写：

| 字段 | 说明 |
|---|---|
| 名称 | 活动名，30 字内 |
| 场次 | 可以加多天多时段，如周六、周日各一场 |
| 地点 | 可点地图选点 |
| 人数 | 填 0 表示不限 |
| 报名开始 | 立即开放，或设定时间到点自动开抢 |
| 报名截止 | 必须早于首场开始 |
| 方式 | 先到先得 / 报名审核 |
| 二课 | 整数学时，填 0 表示不计 |
| 收图方式 | 如「上传群相册，命名姓名-序号」 |
| 附件 | jpg/png/pdf，单个 ≤10MB，默认 30 天过期 |
| 可见范围 | 全体 / 指定部门 |

### 8.2 审核报名

活动详情 →「报名管理」：

- **待审**：通过 / 拒绝；通过时若名额已满，自动进候补；
- **已通过**：可移除（移除后该成员二课自动减少）；
- **候补**：按报名顺序排队，自动递补；
- **请假**：审批通过后自动补人。

### 8.3 二课汇总

「我的」→「二课汇总」：

- 选学年，看到每人总时长；
- 点「导出 CSV」，得到四列：姓名、学号、学院、总时长；
- 部长只能看到本部门发布任务的参与者，主席看全部。

### 8.4 学年切换

「设置」→「开启新学年」：把毕业成员归档、更新当前学年、重新指定部长。

> 学年以 **8 月 1 日** 为界，7 月的活动算旧学年。

## 9. 常见问题

**Q：报名后没收到提醒？**
A：提醒需要报名时点「允许」，且微信只允许一条。可让部长在群里再通知一次。

**Q：名额满了还能去吗？**
A：先点候补，有人退出会自动转正。

**Q：二课学时不对？**
A：活动结束后才计入；如果部长把你移出名单会扣回。找发布活动的部长确认名单。

**Q：为什么看不到某个活动？**
A：活动可能只对指定部门开放。

**Q：换了手机号/宿舍怎么办？**
A：「我的」→ 资料里可以改电话和宿舍；姓名、学号找主席改。

**Q：毕业了账号怎么办？**
A：主席会在学年切换时统一归档，历史记录保留。

**Q：附件过期了还能看吗？**
A：附件默认 30 天过期，文件会删除，但记录和文字说明还在。

## 10. 隐私说明

- 收集：姓名、学号、学院、电话、宿舍号、部门；
- 用途：协会内部活动组织与联络；
- 可见范围：主席全部可见；部长可见本部门发布任务的报名者；同活动成员互相可见姓名与电话；
- 不对外公开，不用于任何商业用途。
