## 3. 只读查数据库

`tcb db nosql execute` 需要传一段 MongoDB 命令 JSON，手写容易出错，仓库里封装了一个只读工具：

```bash
# 统计条数
node scripts/tcb-db.js count members
node scripts/tcb-db.js count members '{"status":"active"}'

# 查记录（默认 20 条）
node scripts/tcb-db.js find members role=chairman 1
node scripts/tcb-db.js find tasks published=true 5

# 临时命令（只允许 find / count / aggregate / distinct / listCollections）
node scripts/tcb-db.js raw '[{"TableName":"tasks","CommandType":"COMMAND","Command":"{\"count\":\"tasks\"}"}]'
```

过滤器两种写法：

| 写法 | 示例 | 说明 |
|---|---|---|
| `key=value` | `role=chairman` | PowerShell 下最省事，`&` 连接多个条件 |
| JSON | `{"role":"chairman"}` | 需要嵌套条件时用；PowerShell 引号容易被吞，建议用 cmd 或 Git Bash |

脚本会拒绝 `insert / update / delete / drop`，只能读。

## 4. 安全红线

1. **AI 默认只读**。任何写操作（改字段、删记录、批量更新）必须先由人确认；
2. **不要 `dump` 整张表**——`members` 有手机号、宿舍、生日，导出即泄露；
3. **不要直接改生产数据**，需要修数据时先备份集合，再写一次性脚本并留下记录；
4. **部署云函数前**先跑 `npm run check`，部署后提醒真人回归测试；
5. 环境 ID 写死为 `gdutpa-d4g3obr8ff2930036`，别用 `prod-...`。

## 7. 常见错误

| 报错 | 原因 | 处理 |
|---|---|---|
| `ResourceNotFound.Namespace` | envId 写错/环境不存在 | 用 `tcb env list` 核对 |
| `登录已过期` | 凭证过期 | `tcb login` 重新扫码 |
| `PermissionDenied` | 账号没有该环境权限 | 找环境拥有者加权限 |
| `command parameter JSON parse failed` | PowerShell 吃掉了引号 | 用 `key=value` 写法或 Git Bash |
| `filter field must be of BSON type object` | 过滤器传成了数字/字符串 | 用 `{}` 或 `key=value` |

## 8. 订阅消息（服务通知）配置

用于两件事：**意见反馈提醒**、**活动开始前 2 小时提醒**。

### 8.1 在公众平台选模板

1. 打开 mp.weixin.qq.com → 功能 → **订阅消息** → 我的模板 → 选用模板；
2. 从模板库选两个：
   - 「反馈/建议提醒」类：需要一个内容字段、一个时间字段；
   - 「活动开始提醒」类：需要活动名称、活动时间、活动地点；
3. 记录每个模板的 **模板 ID**（形如 `abc123...`）和 **字段名**（如 `thing1`、`time2`、`thing3`）。

> 模板字段名每个模板不同，必须和 8.2 的映射一致，否则发送会报 `data format error`。

### 8.2 写入云数据库 configs

| key | value 示例 | 说明 |
|---|---|---|
| `tplFeedback` | `"模板ID"` | 反馈通知模板 |
| `tplActivity` | `"模板ID"` | 活动提醒模板 |
| `ownerOpenid` | `"oX7..."` | 反馈只发到这个人；不填则退回第一位主席 |
| `subscribeFields` | 见下 | 模板字段 → 数据字段映射 |

`subscribeFields` 示例（按你选的模板改字段名）：

```json
{
  "feedback": { "thing2": "name", "thing3": "content", "time6": "time" },
  "activity": { "thing1": "title", "time2": "time", "thing3": "location" }
}
```

不配置 `subscribeFields` 时使用上述默认映射。

### 8.3 授权与发送流程

```
用户点「提交反馈」/「报名成功」
   ↓
wx.requestSubscribeMessage({ tmplIds })   ← 微信弹窗，用户点允许
   ↓
调用云函数（feedback.submit / reminder.create）
   ↓
cloud.openapi.subscribeMessage.send       ← 一次性订阅，一条授权发一条
```

- 一次性订阅：**用户每次授权只能收到一条**，下次发送前需要再次授权；
- 用户拒绝授权不影响主流程，反馈仍会写入站内消息；
- 未配置模板 ID 时，`send` 会跳过，只发站内消息。

### 8.4 活动提醒的定时发送

`cloudfunctions/cron/config.json` 已配置每 5 分钟触发：

```json
{ "triggers": [{ "name": "reminderTick", "type": "timer", "config": "0 */5 * * * * *" }] }
```

部署 `cron` 云函数时选择「上传触发器」，它扫描 `reminders` 中 `status=pending` 且 `remindAt` 到期的记录并发送。

### 8.5 查自己的 openid 填 ownerOpenid

```bash
node scripts/tcb-db.js find members role=chairman 3
```

把返回里的 `_openid` 填到 `configs.ownerOpenid`。
