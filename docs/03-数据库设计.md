# 卡小西 · 数据库设计（审核稿）

| 项目 | 内容 |
|---|---|
| 文档版本 | v0.2（对应需求/技术方案 v0.7） |
| 更新日期 | 2026-11-16 |
| 数据库 | 微信云开发文档型数据库（类 MongoDB） |
| 集合数量 | **9 张** |
| 用途 | 供影协逐表审核，确认后冻结，进入开发 |

> **审核方式**：每张表后面的「审核问题」请逐条给结论；确认无误的表在最后勾选即可。有异议直接说表名 + 字段名。

---

## 0. 全局约定

| 约定 | 说明 |
|---|---|
| 主键 | 云开发自动生成 `_id`（字符串），业务不依赖 |
| 用户标识 | 统一用 `openid`（微信），**不存 unionid** |
| 时间类型 | 全部用 `date`，写库用服务端时间 `db.serverDate()`，不用字符串 |
| 布尔命名 | `published`、`allDay`、`read`（不加 `is` 前缀，保持一致） |
| 软删除 | 业务数据一律不物理删除，用状态或 `cancelledAt` 标记 |
| 冗余字段 | `approvedCount`、`waitlistCount` 为加速列表页的冗余计数，与明细强一致（见 §5） |
| 字符限制 | 标题 30 字、详情 2000 字、备注/原因 200 字、收图方式 200 字 |
| 命名 | 集合小写复数，字段小驼峰，枚举值小写下划线 |

## 2. 表间关系

| 关系 | 类型 | 说明 |
|---|---|---|
| `members` → `task_signups` | 1 : N | 通过 `openid` 关联 |
| `tasks` → `task_signups` | 1 : N | 通过 `taskId` 关联 |
| `tasks` → `leave_requests` | 1 : N | 通过 `taskId` 关联 |
| `tasks` → `reminders` | 1 : N | 每个报名者一条 |
| `tasks` → `calendar_events` | 1 : 0..1 | 通过 `relatedTaskId` 关联（V1.1 自动生成） |
| `tasks` → `todos` | 1 : N | 自动待办通过 `sourceTaskId` 关联 |
| `members` → `todos` | 1 : N | `ownerOpenid` / `creatorOpenid` |
| `members` → `messages` | 1 : N | `openid` |
| `members` → `tasks` | 1 : N | `publisherOpenid` |

> 文档数据库不支持外键，关联字段只做逻辑约束，一致性由云函数保证。

### 5.2 冗余计数一致性

`tasks.approvedCount` 必须等于 `task_signups` 中 `status=approved` 的条数；`waitlistCount` 同理。

- 所有增减都在**事务**里同时改两处；
- 每天 03:00 跑一次对账，不一致写日志并自动修正；
- 出现不一致时的兜底：以明细为准。

### 5.3 附件过期清理

| 项 | 规则 |
|---|---|
| 过期时间 | 附件级 `expiresAt`，**默认 30 天**，可选 90/180 天/永久 |
| 到期处理 | 每日 04:00 清理任务：删除云存储文件，**保留** `attachments` 元数据（name/size/ext），`fileID` 置空并标记 `expired: true` |
| 文字 | 任务标题、详情、备注、消息正文**永久保留**，不做 TTL |
| 封面 | 同附件规则，默认永久 |
| 效果 | 存储只涨文字和少量元数据，图片/PDF 按需淘汰 |

## 8. 设计确认表（全部已确认，可冻结）

| # | 结论 | 落点 |
|---|---|---|
| 1 | 学号固定 10 位数字 + 唯一 | `members.studentNo` 唯一索引，正则 `/^\d{10}$/` |
| 2 | 手机号必填 | `members.phone` 必填 + 11 位校验 |
| 3 | 宿舍格式：东西 + 中文楼号 + 房号 | `members.dorm` 正则 `^[东西][一二三四五六七八九十]+[0-9]{3,4}$` |
| 4 | 多天多时段 | `tasks.sessions[]`，`startAt/endAt` 为推导包络 |
| 5 | 人数可不限 | `tasks.quota = 0` 表示不限 |
| 6 | 二课学时为整数（2/4/8） | `tasks.erkeHours` 整数 |
| 7 | 附件仅图片 + PDF | 白名单 jpg/png/webp/pdf，单个 ≤10MB、≤5 个 |
| 8 | 附件默认 30 天过期 | `attachments[].expiresAt`，每日 04:00 清文件留记录 |
| 9 | 报名备注选填 | `task_signups.note` 非必填 |
| 10 | 被拒后可再报名 | 原记录改回 `pending`、重新取 `queueNo` |
| 11 | 请假不限次数 | 无次数限制，全走审批 |
| 12 | 只提醒首场前 2 小时 | `reminders.remindAt = startAt - 2h` |
| 13 | 年历不做重复事件 | 无 recurrence 字段 |
| 14 | 部门待办可指派部长本人 | `todos.ownerOpenid` 不限角色 |
| 15 | 三条自动待办全保留 | `autoRule`：confirm_list / onsite / collect |
| 16 | 站内消息永久保留 | 无 TTL，不自动清理 |

> 至此数据库设计冻结。开发中以本文件为准，字段有变动先改这里。
