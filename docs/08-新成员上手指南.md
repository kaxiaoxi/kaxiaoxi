# 卡小西 · 新成员上手指南（零基础）

> 这份文档假设你**从没用过 Git、也没写过小程序**。照着做，半小时内能让项目在你电脑上跑起来，并学会安全地改代码、提交、合并。

---

## 0. 先搞清楚三件事

| 名词 | 一句话解释 |
|---|---|
| **Git** | 记录代码每次修改的工具，能回退、能多人同时改 |
| **Gitee** | 存放代码的网站（国内版 GitHub），我们的仓库在这里 |
| **微信开发者工具** | 写小程序、预览、上传版本的官方软件 |

你不需要懂服务器、数据库部署——后端用的是微信云开发，代码推上去、云函数点一下部署就能用。

## 2. 第一次配置（约 15 分钟）

### 2.1 验证 Git 装好了

打开「命令提示符」或 PowerShell，输入：

```bash
git --version
```

出现 `git version 2.x.x` 就成功。

### 2.2 告诉 Git 你是谁

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

> 这两项会写进每次提交记录，方便知道是谁改的。

### 2.3 把代码下载到电脑

选一个**没有中文、没有空格**的目录，比如 `D:\code`，然后：

```bash
cd /d D:\code
git clone https://gitee.com/yjy666ryan/kaxiaoxi.git
cd kaxiaoxi
```

第一次会要求输入 Gitee 账号密码——**密码处填「私人令牌」**，不是登录密码：

> Gitee → 头像 → 设置 → 安全设置 → 私人令牌 → 生成新令牌（勾选 `projects`）→ 复制粘贴。

### 2.4 安装代码检查工具（可选）

在项目根目录执行：

```bash
npm install
```

装完可以用 `npm run check` 检查代码格式。

## 4. 项目长什么样

```
kaxiaoxi/
├── miniprogram/            小程序前端
│   ├── pages/              每个页面对应一个目录
│   │   ├── launch/         启动分流
│   │   ├── join/           注册、等待审核
│   │   ├── home/           首页
│   │   ├── task/           任务列表、详情、发布、报名管理
│   │   ├── calendar/       年历
│   │   ├── todo/           待办
│   │   ├── message/        消息
│   │   ├── mine/           我的、我的二课
│   │   ├── profile/        编辑资料
│   │   └── admin/          成员管理、二课汇总、设置
│   ├── services/api.js     所有接口调用都经过它
│   ├── utils/              工具函数
│   └── styles/             全局样式变量
├── cloudfunctions/         后端（云函数）
│   ├── api/                唯一业务入口，按 action 路由
│   ├── cron/               定时任务
│   └── init/               初始化
├── docs/                   全部文档
├── seed/                   预导入名单
└── project.config.json     工程配置（不要随便改）
```

**一个页面 = 四个文件**：`index.js`（逻辑）、`index.json`（配置）、`index.wxml`（结构）、`index.wxss`（样式）。

## 5. 改代码的完整流程（最重要）

> 核心原则：**永远不在 `develop` 或 `main` 上直接改**，每次开一个新分支，改完合并回去。

### 第 1 步：更新到最新

```bash
git checkout develop
git pull
```

### 第 2 步：开一个属于你的分支

命名规则：`feature/功能名` 或 `fix/问题名`，全小写、用 `-` 连接。

```bash
git checkout -b feature/home-banner
```

### 第 3 步：改代码

比如想改首页文案，打开 `miniprogram/pages/home/index.wxml`，改完保存。

开发者工具会自动重新编译，模拟器里立刻能看到效果。

### 第 4 步：本地检查

```bash
npm run check
```

有报错就按提示修，通过后再提交。

### 第 5 步：提交

```bash
git status                  # 看改了哪些文件
git add .                   # 全部加入本次提交
git commit -m "feat(home): 首页增加活动横幅"
```

提交信息格式：`类型(模块): 做了什么`

| 类型 | 用在什么时候 |
|---|---|
| `feat` | 新功能 |
| `fix` | 修 bug |
| `docs` | 只改文档 |
| `style` | 只改格式 |
| `refactor` | 重构，功能不变 |
| `chore` | 配置、依赖、脚本 |

模块写：`home`、`task`、`signup`、`calendar`、`todo`、`erke`、`auth`、`cloud`、`docs`。

### 第 6 步：推送

```bash
git push -u origin feature/home-banner
```

### 第 7 步：在 Gitee 提合并请求（PR）

1. 打开 https://gitee.com/yjy666ryan/kaxiaoxi
2. 页面顶部会出现「新建 Pull Request」提示，点它；或左侧「Pull Requests」→ 新建；
3. 源分支选 `feature/home-banner`，目标分支选 `develop`；
4. 标题写清楚，描述里写：改了什么、怎么测的、影响哪些页面；
5. 提交，等负责人 review 后合并。

### 第 8 步：合并后清理

```bash
git checkout develop
git pull
git branch -d feature/home-banner
```

## 6. 不想用命令行？用工具自带的版本管理

1. 开发者工具顶部「版本管理」；
2. 左侧「工作区」勾选要提交的文件；
3. 下方填提交信息 → 点「提交」；

> 命令行更稳，建议至少学会 `pull / checkout / add / commit / push` 五个命令。

## 7. 代码规范速查（详细见 docs/05）

| 场景 | 必须这样做 |
|---|---|
| 页面文件 | 目录 + `index.js/json/wxml/wxss`，并在 `app.json` 的 `pages` 里注册 |
| 数据请求 | 用 `services/api.js` 的 `call(action, payload)`，**不要**直接 `wx.cloud.database()` |
| 页面数据 | `setData` 只传变化的字段，不要整个对象重设 |
| 列表渲染 | `wx:for` 必须带 `wx:key` |
| 云函数 | 新功能在 `cloudfunctions/api/router.js` 注册 action，并做权限判断 |
| 时间 | 写数据库用 `db.serverDate()`，不要用手机时间 |
| 命名 | 文件 kebab-case，变量 camelCase，常量 UPPER_SNAKE |
| 禁止 | `var`、`==`、`console.log`、空 `catch`、把权限判断写在前端 |

改数据库字段前，先改 `docs/03-数据库设计.md`，再改代码。

## 8. 常见问题

**Q1：导入项目提示「无权限」**
让负责人把你的微信加为小程序开发者，重新扫码登录。

**Q2：编译后一片空白**
先看「调试器 → Console」的红色报错。常见原因：
- 页面没在 `app.json` 注册；
- 某个 `require` 路径写错；
- 改完没点「编译」。

**Q3：接口报「服务异常」**
云函数没部署，或部署失败。右键 `cloudfunctions/api` → 上传并部署 → 云端安装依赖。

**Q4：云函数改了没生效**
云函数不会热更新，必须重新部署。

**Q5：数据库报 collection not exists**
第一次调用会自动建集合；如果还报，手动跑一次 `init` 云函数。

**Q6：`git push` 要求输密码**
填 Gitee **私人令牌**，不是登录密码。

**Q7：push 被拒绝（rejected）**
别人先推了新代码：
```bash
git pull --rebase
git push
```

**Q8：改错了想撤销（还没提交）**
```bash
git checkout -- 文件路径
```

**Q9：提交了不该提交的文件**
```bash
git rm --cached 文件路径
git commit -m "chore: 移除误提交文件"
```

**Q10：真机上看不到效果**
点「预览」扫码；如果接口报错，检查手机网络和云环境是否正确。
