# 变更记录

格式：`版本 · 日期 · 变更摘要`

## v1.0.0 · 2026-11-17（MVP 功能齐）

- 二课：我的二课（实时聚合明细）、学年汇总、CSV 导出（姓名/学号/学院/总时长）
- 消息中心：报名结果、候补转正、请假结果、资料修改、入会审核均写入站内信
- 设置：学年切换、按学号移交主席
- 全部 20 个页面完成，云函数 23 个文件

## v0.5.0 · 2026-11-17

- 年历模块：月视图、当日事件、事件详情、新建/编辑/删除（软删）
- 待办模块：我的/部门/已完成、新建/编辑/完成/删除、重要性排序
- 任务发布时自动生成两条待办：确认名单、核对名单+收图
- 首页接入待办，我的页新增「我的待办」入口

## v0.4.0 · 2026-11-17

- 报名管理页：待审 / 已通过 / 候补 / 请假 四个分组
- 审核报名：通过时满员自动转候补，拒绝直接置为已拒
- 请假递补：成员提交请假 → 主席审批 → 准假后名额自动给候补第一位
- 移除名单：释放名额并自动递补
- 任务详情新增「报名管理」入口与「请假」按钮

## v0.3.0 · 2026-11-17

- 任务模块：发布（多场次/人数不限/定时报名/指定部门）、列表、详情、报名、取消
- 云函数新增 `task.create/list/detail/apply/cancelApply/mine`
- 报名支持先到先得与审核两种模式，满员进候补，取消后自动递补
- 首页接入真实任务数据，任务列表加「发布」入口

## v0.2.0 · 2026-11-17

- 新增登录分流：`auth.login` 按 openid 返回 new/pending/active/rejected
- 新增注册：`auth.register`，6 项校验、学号唯一、状态 pending
- 新增主席审核：`member.review`（通过/拒绝）、`member.list`
- 页面：注册表单、等待审核页、首页/我的接入真实成员数据
- 云函数拆分为 `router + actions + lib`，统一错误码
