# 变更记录

格式：`版本 · 日期 · 变更摘要`

## v1.6.1 · 2026-11-23（申请页刷新按钮）

- 「刷新状态」不再使用原生 loading 图标，避免图标挤占文字空间
- 改为按钮内自定义旋转指示器，文字位置保持居中不变
- 刷新过程中重复点击会被忽略，不会重复请求

## v1.6.0 · 2026-11-23（访客模式）

- 信息注册页新增「访客登录」：无需注册即可进入小程序
- 访客数据只存本机（`guest.session.v1`），退出即清除，不上云
- 访客仅可查看首页/我的/关于，可改本机昵称与学院
- 任务、年历、待办、报名、消息、二课、成员管理、设置等全部不可用
- 新增全局拦截：访客状态下所有云函数调用直接拒绝，确保数据隔离

## v1.5.4 · 2026-11-20（年历卡片）

- 年历当日安排卡片左右各加宽 10rpx，并增加上下内边距与行高
- 日程行间距更舒展，内容不再贴着卡片边缘

## v1.5.3 · 2026-11-20（首页视觉对齐）

- 问候区、分区标题与卡片统一到同一左右边界，头像右缘与卡片右缘对齐
- 统一分区标题的上下间距，首页纵向节奏更一致

## v1.5.2 · 2026-11-20（分享封面兼容）

- 分享封面改用云存储临时地址（`wx.cloud.getTempFileURL`），提升部分机型上分享卡片的显示兼容性
- 取不到云端地址时自动回退到包内图片 `images/share-cover.png`

## v1.5.1 · 2026-11-20（分享页重做）

- 新增独立分享落地页 `pages/task/share`：品牌头图 + 任务信息 + 一键查看详情并报名
- 分享卡片改用自定义封面 `images/share-cover.png`，不再截取当前页面
- 详情页「分享」和发布页「发布并分享」都指向该落地页
- 分享落地页支持未登录/无权限时的错误提示与重试

## v1.5.0 · 2026-11-20（报名流程调整）

- 移除「取消报名」：报名后不能自行取消，只能走请假
- 请假改为提交即生效，名额自动顺延给候补第一位，不再需要部长审批
- 请假生效后给本人和发布人发送站内消息
- 发布页新增「发布并分享」：创建任务后跳转详情，可直接分享到群聊报名

## v1.4.3 · 2026-11-19（选人面板）

- 日程、待办的负责人选择改为可搜索面板：按部门分组、支持关键字搜索，替换原生滚轮 picker
- 选人列表带角色标签和头像底色，重名也能区分
- `member.options` 增加 `avatarText`、`avatarColor` 两个返回字段

## v1.4.2 · 2026-11-19（发布与分工体验）

- 分工情况改为按分工列出成员姓名，不再显示场次计数
- 发布页「先到先得」「指定部门」移到左侧，可见范围默认「指定部门」
- 开启分工后「需要人数」只读，自动汇总各分工人数
- 新增场次默认以上一场的结束时间作为开始时间，结束时间顺延 3 小时

## v1.4.1 · 2026-11-19（二课按场累计）

- 二课学时改为「每场学时」：报名 N 个时段就计 N × 每场学时（2 场 × 2 学时 = 4 学时）
- 任务详情新增「分工情况」：按分工 × 场次显示已报名人数 / 名额
- 二课明细与汇总同步按报名场次计算

## v1.4.0 · 2026-11-19（分工与时段报名）

- 发布任务：需要人数默认留空（0 = 不限），二课学时默认 2
- 新增「按分工报名」开关：可自由添加分工名称与人数，名额按**每个时段**单独计算
- 报名：多时段任务支持勾选多个时段；开启分工后支持多选分工，一次提交
- `tasks` 新增 `useRoles`、`roles`；`task_signups` 新增 `sessions`、`roles`

## v1.3.0 · 2026-11-19（提醒模块）

- 修正订阅授权时机：`requestSubscribeMessage` 从 `await` 之后挪到点击处理函数里，避免 `can only be invoked by user TAP gesture`
- 新增待办截止提醒：加入协作时登记，截止当天 09:00（北京时间）发送
- `cron` 增加站内信兜底：无论微信推送成功与否都写一条 `type: remind` 的消息
- `cron` 增加失败重试（最多 2 次），模板缺失/拒收类错误不重试，直接记 `failed` / `cancelled`
- 新增 `reminder.createTodo`、`reminder.status` 两个 action
- 新增「我的 → 提醒设置」页：显示两种提醒的开通状态与待发送/已发送/失败统计
- `reminders` 表新增 `kind`、`todoId`，支持活动与待办两类提醒共用一张表

## v1.2.0 · 2026-11-19（年历与待办重做）

- 年历：新增结束日期、时间文本、主/副负责人、6 种状态、提醒日字段；类型扩到 10 类并兼容旧数据
- 年历：新增「公开 / 内部」两档可见范围，内部日程在云函数查询条件里过滤，小干取不到数据

- 待办：新增加入 / 退出协作，用 `addToSet` / `pull`，无需审批
- 待办：新增详情页，列表改为四个 tab（我的 / 部门 / 内部 / 已完成）
- 任务发布时自动在年历落一条事件；自动待办改为对本部门可见
- 新增 action：`member.options`、`calendar.list`、`todo.join`、`todo.quit`
