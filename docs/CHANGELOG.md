## v1.1.0-dev · 2026-11-19（feature/ui）

- 确定本轮界面视觉方向，以原生分组卡片为基础，局部使用半透明液态玻璃
- 校准颜色令牌和小字号对比度，统一卡片、圆角、玻璃层级与按压反馈
- 新增自定义毛玻璃 TabBar，保留原 4 个入口、页面顺序和图标
- 首页、任务列表、年历、我的和任务详情统一为分组卡片布局，并补齐加载、空态和错误重试
- TabBar 增加滑动玻璃胶囊、图标交叉淡入和页面轻淡入；动效调整为 340ms 胶囊、280ms 页面缓动
- 新增统一 Bottom Sheet 组件，接入报名确认、请假填写、移出名单、准假/拒绝请假
- 修正 Bottom Sheet 操作按钮的垂直居中、加载锁定、遮罩关闭和下滑关闭
- 新增两套视觉探索效果板，保存在 `docs/ui-concepts/`
- 微信开发者工具编译检查通过；`npm run check` 为 0 error，保留原有云函数未使用变量 warning

验证与部署：

- 已完成真机测试并进行人工确认
- 云函数未改动，本轮无需重新部署
- 后续如覆盖更多机型，继续关注毛玻璃渲染、低端 Android 滚动性能和键盘弹出表现
