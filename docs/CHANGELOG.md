# 变更记录

格式：`版本 · 日期 · 变更摘要`

## v1.4.0 · 2026-11-19（分工与时段报名）

- 发布任务：需要人数默认留空（0 = 不限），二课学时默认 2
- 新增「按分工报名」开关：可自由添加分工名称与人数，名额按**每个时段**单独计算
- 报名：多时段任务支持勾选多个时段；开启分工后支持多选分工，一次提交
- `tasks` 新增 `useRoles`、`roles`；`task_signups` 新增 `sessions`、`roles`

## v1.3.0 · 2026-11-19（提醒模块）

- 修正订阅授权时机：`requestSubscribeMessage` 从 `await` 之后挪到点击处理函数里，避免 `can only be invoked by user TAP gesture`
- 新增待办截止提醒：加入协作时登记，截止当天 09:00（北京时间）发送
- `cron` 增加站内信兜底：无论微信推送成功与否都写一条 `type: remind` 的消息
- `cron` 增加失败重试（最多 2 次），模板缺失/拒收类错误不重试，直接记 `failed` / `cancelled`
- 新增 `reminder.createTodo`、`reminder.status` 两个 action
- 新增「我的 → 提醒设置」页：显示两种提醒的开通状态与待发送/已发送/失败统计
- `reminders` 表新增 `kind`、`todoId`，支持活动与待办两类提醒共用一张表

## v1.2.0 · 2026-11-19（年历与待办重做）

- 年历：新增结束日期、时间文本、主/副负责人、6 种状态、提醒日字段；类型扩到 10 类并兼容旧数据
- 年历：新增「公开 / 内部」两档可见范围，内部日程在云函数查询条件里过滤，小干取不到数据
- 年历：新增部长/主席专用列表视图（首列固定、横向滚动），不做行内编辑
- 待办：可见范围改为四档（仅自己 / 本部门 / 全体 / 内部），新增 `participants` 协作人
- 待办：新增加入 / 退出协作，用 `addToSet` / `pull`，无需审批
- 待办：新增详情页，列表改为四个 tab（我的 / 部门 / 内部 / 已完成）
- 任务发布时自动在年历落一条事件；自动待办改为对本部门可见
- 新增 action：`member.options`、`calendar.list`、`todo.join`、`todo.quit`

## v1.1.0 · 2026-11-19（界面改版）

- 确定本轮界面视觉方向，以原生分组卡片为基础，局部使用半透明液态玻璃

- 新增自定义毛玻璃 TabBar，保留原 4 个入口、页面顺序和图标
- 首页、任务列表、年历、我的和任务详情统一为分组卡片布局，并补齐加载、空态和错误重试
- TabBar 增加滑动玻璃胶囊、图标交叉淡入和页面轻淡入；动效调整为 340ms 胶囊、280ms 页面缓动
- 新增统一 Bottom Sheet 组件，接入报名确认、请假填写、移出名单、准假/拒绝请假
- 修正 Bottom Sheet 操作按钮的垂直居中、加载锁定、遮罩关闭和下滑关闭
- 新增两套视觉探索效果板，保存在 `docs/ui-concepts/`
- 微信开发者工具编译检查通过；`npm run check` 为 0 error，保留原有云函数未使用变量 warning
