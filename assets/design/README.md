## 使用注意

- 小尺寸（≤120px）建议用简化版：去掉镜头环内的中英文环字，否则缩小时糊成一团；
- 不拉伸、不改主色、不加投影；
- 当前只有 1 个姿态，建议补 3 个：开心（报名成功）/ 提醒（活动提醒）/ 抱歉（名额已满）。
