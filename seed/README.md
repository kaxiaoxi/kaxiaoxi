# 预导入名单（部长 / 主席）

`members.csv` 由 `设计稿` 里的部长名单整理而来，共 18 人，其中 5 人角色为 `chairman`：

- 彭奕嘉、黄家锐、杨健宇、郭绍文、陈锦华

其余 13 人为 `minister`。

## 已做的规范化

| 项 | 处理 |
|---|---|
| 宿舍 | `东9-708` → `东九708`、`西11 630` → `西十一630`、`西13-539` → `西十三539` |
| 生日 | `2006.6.26` → `2006-06-26`，统一 `YYYY-MM-DD` |
| 学号 | 全部为 10 位数字，符合新校验规则 |
| 状态 | `active`，导入后即可直接使用，无需审核 |
| 部门 | 表格里没有，留空；本人注册时选择 |

## 导入步骤（微信开发者工具）

1. 打开项目中用到的环境：云开发控制台 → 数据库 → `members`；
2. 点「导入」→ 选择本目录的 `members.csv`；
3. 冲突处理选「插入」→ 开始导入；
4. 导入完成后，让这 18 人各自打开小程序：
   - 在「完善资料」里填**与表格一致的真实姓名 + 学号**，其余按自己情况填；
   - 提交后系统会自动把学号与微信绑定，直接进入首页，**不需要主席审核**；
   - 姓名和学号对不上会提示「姓名与学号不匹配」。

> 如果 `members` 里已经有测试数据，建议先清空再导入，避免学号重复。

## 字段说明

`name, studentNo, college, phone, dorm, dept, role, status, birthday, academicYear, avatarText, avatarColor`

- `dept` 留空：注册认领时会用本人选择的部门补上；
- `role`：`chairman` / `minister`；
- `status`：`active`。
