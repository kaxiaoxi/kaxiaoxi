## 已定决策

| 决策 | 结论 |
|---|---|
| 范围 | 仅影协内部，不对外开放，无游客浏览 |
| 主体 | 个人主体（无微信认证、无支付） |
| 组织 | 主席 / 部长 / 小干；摄影师队 / 宣传部 / 运营部 |
| 权限 | 部长管本部门；审核权随任务走（谁发布谁审）；主席兜底 |
| 任务 | 名称、**多天多时段**、详情+附件（图片/PDF）、地点、人数、报名开始、**报名截止**、二课学时（整数）、收图方式、可见范围 |
| 报名 | 先到先得 / 报名审核；定时开抢；满员进候补 |
| 请假 | 随时可提、不限次数，全部由部长/主席审批；通过后候补自动递补 |
| 发布 | 统一入口：搬砖（任务）/ 部门待办 / 年历日程 |
| 到场 | **不做到场登记**；名单可手动移除 |
| 二课 | 只填本次学时（整数 2/4/8）；**实时统计，不落流水、无结算**；导出姓名/学号/学院/总时长四列 |
| 待办 | 个人 + 部门，三级重要性；任务自动生成待办 |
| 状态 | 活动只有「未开始 / 进行中 / 已结束」三态，按时间自动推导，无手工流转 |
| 提醒 | 首场开始前 2 小时订阅消息（用户报名时点同意，一次性） |
| 资料 | 学号唯一（业务主键）、手机号必填；学号/电话/宿舍按角色与任务可见 |
| 附件 | 仅 jpg/png/webp/pdf，单个 ≤10MB、≤5 个；可设过期时间，到期删文件留记录 |
| 消息 | 站内消息永久保留，文字不清理 |
| 交付/图片 | 不做交付；除任务封面/附件外不上传图片 |
| 后台 | 只做小程序，不做网页端 |
| 学年 | 手动开启新学年并归档；**8 月 1 日为学年边界** |
| 规模 | 约 70 人/学年，年度轮换 |
